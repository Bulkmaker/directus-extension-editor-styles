# AGENTS.md

Directus endpoint extension that serves CSS for WYSIWYG editors: predefined classes for image formatting, applied through rich text editor toolbar buttons.

## Commands

```bash
npm install
npm run build   # production build to dist/
npm run dev     # watch mode
```

No tests, no lint config.

## How it works

- Source: `src/index.ts`, the CSS lives in the `editorStyles` template literal.
- Endpoint: `GET /editor-styles/styles.css`, response `text/css`, `Cache-Control: public, max-age=86400` (24h).
- Meant to be loaded by TinyMCE through the `content_css` option of a Directus WYSIWYG field: `content_css: '/editor-styles/styles.css'`.

## CSS classes

| Class | Effect |
|-------|--------|
| `.full-width` | image 100% width |
| `.img-responsive` | max-width 100%, auto height |
| `.shadow` | box shadow with border-radius |
| `.border` | border with padding |
| `.float-left`, `.float-right` | float with margin |
| `.center` | center block element |

To add a style: edit the `editorStyles` literal in `src/index.ts`, rebuild, and add the class to the table above and to README/CHANGELOG if the change is user-visible.

## Build and release

- `dist/` is generated by GitHub Actions on push to `src/**`, `package.json`, `tsconfig.json`; do not edit it manually.
- Release: add an entry to `CHANGELOG.md` and push a tag `vX.Y.Z`; the release workflow rebuilds dist and moves the tag.
- Dependencies: `@directus/extensions-sdk` (extension framework, host `^10.0.0 || ^11.0.0`).
